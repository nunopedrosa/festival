# Changelog

## Deployment tooling — 2026-11-01

Add DreamHost pull-only deployment script, committed generated public-file manifest, preserve-existing Apache header template, public GitHub setup documentation and 17 isolated deployment regression checks. Runtime version remains 1.1.0.

## 1.1.0 — 2026-11-01

Normalize calendar selector appearance and control heights, align the desktop toolbar, and retain a compact two-row mobile layout. Expand to all 249 ISO countries/territories plus Kosovo and the Canary Islands, with 207 local rule calendars and 44 packaged national calendar supplements. Bundle all flags and bilingual country names, preserve existing preferences/backups, and mark calendars with no available events clearly.

## 1.0.2 — 2026-11-01

Country column headers show the country code with its flag underneath, keeping the 44 px column width. Flag SVGs are bundled locally and cached for offline use; full accessible country names are retained.

## 1.0.1 — 2026-11-01

Fix missing holiday symbols by embedding SVG paths directly in cells, the legend and details instead of external sprite references. Country headers display codes only, with full accessible names retained. Country columns are 44 px wide and no longer stretched to fill the table. Release/cache markers bumped together; preferences and backups remain compatible.

## 1.0.0 — 2026-10-31

Initial local-first PWA: European holiday rules, 58 country/territory selections, compact SVG comparison grid and agenda, region selection, date/coincidence/type filters, EN/pt-PT, backup/restore, app manifest, controlled updates and offline preparation. Portuguese regional/local amendments and source attribution. Automated calculation, preference and cache tests.
